---

## 2. Connexion et authentification (SSO)

Tous les services utilisent **une connexion unique (SSO)** avec vos identifiants universitaires.

```
Identifiant : prenom.nom@universite.cm
Mot de passe : fourni par votre administration (à changer à la première connexion)
```

**En cas de problème de connexion :**
1. Cliquer sur "Mot de passe oublié" sur la page de connexion
2. Saisir votre email universitaire
3. Suivre les instructions reçues par email
4. Si le problème persiste, contacter le support (voir section 5)

---

## 3. Accès à Moodle

1. Aller sur `https://moodle.[votre-cdnu].cdnu.cm`
2. Cliquer sur "Connexion" (en haut à droite)
3. Utiliser vos identifiants universitaires (SSO)
4. Vos cours apparaissent dans "Mon espace" → "Mes cours"

---

## 4. Stockage et partage de fichiers

- **Quota individuel :** 10 Go par étudiant, 50 Go par enseignant
- **Types de fichiers acceptés :** PDF, DOCX, PPTX, MP4, ZIP (max 500 Mo par fichier)
- **Durée de conservation :** Fichiers actifs conservés indéfiniment, archives après 2 ans d'inactivité
